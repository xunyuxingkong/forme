# 0.4 功能与玩法升级记录

日期：2026-10-10。版本：0.4.0。本批范围：家具布置、组合事件、伙伴藏物、操作反馈和芽芽/小猫局部精修。按用户要求，性能专项采样、GPU、长时间和低端设备验收后置。

## 可用功能

- “玩耍与生活”集中提供生活事件、藏物、纸船和抛接球。“布置→进入家具编辑”也能进入编辑器。
- 书架、暖灯、零食碗、小窝、鱼缸和坐垫可拖动、以0.25m吸附、旋转90°、复制、收纳、添加、撤销最近20步。最多24件。保存前检查边界、家具重叠、伙伴起点和各家具的可达位置；非法布置保留预览但不能保存。书桌、沙发、墙体和前庭固定设施不在本批编辑范围。
- 阅读角模板可一次应用基本6件家具的组合，替换的是未保存草稿，可撤销；保存才落盘。取消/离开编辑页恢复已保存布局。
- 8条规则：阅读角、听雨读书、窗边晒太阳、零食小憩、鱼缸观察、暖灯晚安、夜读、花园歇脚。由实际家具位置、天气、昼夜和灯光决定；界面展示条件，完成相应前往/开始互动后进入图鉴，重复发现不重复记录。当前为用户主动体验事件，尚未实现后台自主生活选择器。
- 藏物支持“我藏、伙伴找”和“伙伴藏、我找”。玩家可点击家具或使用侧栏选择；提示来自实际家具的前后/左右位置。伙伴逐个前往可达家具，小猫优先检查鱼缸、芽芽优先检查坐垫。找到后显示小球并欢呼；无失败扣分、体力和等待门槛，随时可结束。此轮未做复杂视线遮挡推理。
- 物件悬停显示地面高亮框，右键提供最多4项菜单。地面移动显示目标及实际寻路节点，被家具或边界阻挡时提示原因。家具编辑和玩具抓取优先于镜头拖动，旋转拖动阈值为6个逻辑像素。
- 小球可拿起，按Shift拖动预览抛物线和落点，松开投掷；也有方向按钮。落地后伙伴再去捡。飞行采用单调时钟，隐藏、停止或系统暂停清理飞行与移动；减少动效直接落地。原投球入口也使用该过程。
- 顶部“伙伴控制”在各页面提供叫回和停止，场景中也保留快捷入口。顶部可收起/展开侧栏；760×760活动窗口上下显示场景和操作区，极小窗口改为活动/场景切换，操作区可滚动。

## 模型与动作

芽芽调整身体比例和配色，增加腹部细节、叶脉与独立叶耳，按开心、思考、休息及倾斜改变叶耳姿态。小猫增加三角耳形、独立耳部和尾巴，耳朵回应情绪，尾巴回应步态；保留独立爪部放船动作。静态几何冻结共享，模型实例仅改变自己的变换。

仍采用现有本地几何模型和语义动作适配器，没有新增引擎、模型下载器或网络资产依赖。这是芽芽与小猫的局部精修，不代表四种角色、完整骨骼资产管线、材质灯光及室内外全场景重制完成。狐狸/企鹅统一精修、第二批场景、AI共同创作及花园弹球仍属于后续阶段。

## 项目准则与数据

核心玩法、寻路、组合判断和收藏均本地执行，AI请求数为0。没有新增自动总结、自动上传、屏幕采集或聊天共享。网络响应不会阻塞拖拽、取消和小游戏。

家具布局和最多8个发现ID保存在本机SQLite的living-world设置项，普通记录未额外加密。藏物目标、线索、检查过程和抛球状态仅在内存，结束/退出清除，没有自动行为日志。游戏状态不自动加入AI请求。

JSON备份格式升至5，接受1–5版本，小屋类别导出包含World家具与图鉴；旧备份缺少World字段时保留现有布局和发现。导入布局检查数量、类型、有限数值、重复ID、重叠和可达性，沿用事务及恢复备份。SQLite版本仍为4，没有新增数据库迁移。

图鉴可在“玩耍与生活→重置生活图鉴”单独清除，并删除应用管理的恢复备份。家具可收纳/恢复基本摆法，再明确保存；设置中可导出、导入或清除全部个人数据。外部导出副本需自行处理。

资源取舍：不新增后台生活循环；小球计时器仅飞行期间启动，收藏和操作历史有界，场景缓存仍最多2个。家具复制会增加渲染内容，因此上限24件，不承诺所有设备在上限下均流畅。功能生命周期检查保留，专项性能测试按用户要求后置，未宣布达到既定资源预算。
