# 智谱官方接入（2026-10-12）

新增“智谱官方 · GLM”服务预设，普通API入口 `https://open.bigmodel.cn/api/paas/v4`，默认 `glm-5.3-flash`。沿用现有HTTP客户端、Bearer鉴权和SSE正文显示，不引入SDK或新依赖。

## 官方协议与范围

- [OpenAI兼容说明](https://docs.bigmodel.cn/cn/guide/develop/openai/introduction)：普通官方入口、Bearer密钥及流式正文结构。
- [GLM-5.3-Flash说明](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash)：模型代码、原生多模态及强制思考。
- [对话补全API](https://docs.bigmodel.cn/api-reference/%E6%A8%A1%E5%9E%8B-api/%E5%AF%B9%E8%AF%9D%E8%A1%A5%E5%85%A8)：low/high/max、clear_thinking、PNG/JPEG、file.file_data和filename。官方图片对象不带OpenAI的detail字段。

用户在高级连接设置选择低、较高、最高强度，保存AI配置后生效。默认low；只给精确匹配的普通官方入口和GLM-5.3、5.3-Flash/FlashX附加该参数，启用思考、清除跨轮思考。其他模型及服务保持既有参数。旧设置缺少强度时默认low，非法强度本地拒绝，无需数据库迁移。

图片以PNG/JPEG发送；PDF使用已有原文件内嵌格式，不借助外部文件托管或OCR。WebP本地拒绝，用户自行转换；页面转换后的PNG也可使用现有图片结构。原附件依然仅本轮发送。服务商身份保留原custom标识，兼容已有自定义智谱配置的记忆和备份；切换平台仍须新密钥，新地址新建对话，不自动迁移历史。

- 成本：新增预设和强度选择不联网；只有主动发送/测试才调用服务。无自动重试、工具调用或额外上传接口。保留原文字预算与输出上限，不为了思考静默提升额度；智谱连接测试采用用户已保存的输出上限，避免原固定128额度与强制思考冲突。更高强度可能增加用量，界面提供说明；不承诺价格或实际账单。
- 延迟：有效推理片段更新流式停滞计时，避免有进展的推理被当作失联；不向界面冒充正文。90秒总时限不延长，用户仍可停止。空正文提示检查输出上限并手动重试；不保证真实服务的首字延迟。
