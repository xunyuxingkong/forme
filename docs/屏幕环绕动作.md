# 屏幕环绕动作

0.5.5增加“整个屏幕跑两圈”等表达。默认本地规则将一圈/两圈映射为有限的屏幕工作区边缘路线；发送预览可确认本地路径，命中后不联网。只在桌面伙伴悬浮模式可用，使用当前显示器的工作区（避开任务栏），不读取其它窗口内容。需要开启宠物动作权限；路线最多两圈、随时停止，动作组遵守30秒上限。减少动效开启时按该模式直接到达路线终点。规则或权限未命中时会明确报告，不声称已完成。

移动沿工作区四角插值，并复用桌宠现有动画回调，不增加常驻定时器。移动长度取决于显示器工作区尺寸；30秒上限用于限制动作持续时间，较大的显示器或缩放环境可能中止并反馈。

验证：Release编译0警告、0错误；安装包隔离解包自检通过。屏幕环绕通过编译与执行边界检查，本轮没有运行Core自动化测试或真实桌面窗口演练。
