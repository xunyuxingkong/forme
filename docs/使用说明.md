# 欢迎来到 Forme

双击同目录的 `Forme.exe` 可免安装运行。安装版可以从桌面或开始菜单打开。需要 Windows 11 x64；运行时已包含，无需安装开发工具。

首次启动可以给伙伴起名，AI 连接可跳过。

- 3D 小屋：拖动调整视角，滚轮调整远近，点击“复位视角”恢复。小窗口中点击“查看3D小屋 / 返回活动”切换。
- 点击伙伴聊天、书桌专注、心情本记录、沙发放松、植物浇水。底部按钮可以进入同样的活动。
- 关闭小屋后伙伴回到桌面。拖动移动，点击打开快捷入口，右键设置置顶、安静或收起。
- 托盘中可以打开小屋、显示伙伴、收起或退出。关闭小屋并不退出程序。
- 专注和休息均需主动开始，锁屏、睡眠或退出时会暂停；恢复后可继续。
- 未开始的专注任务和时长在本次运行中保留，切换页面或设置不会清空；退出程序后清除，不会自动发送给 AI。
- 揉揉伙伴、戳泡泡和呼吸节奏无需联网。植物每天可浇水一次，不会枯萎。
- 花园中标注“成长盆栽”的植物会随浇水成长；花坛及灌木属于装饰。
- 心情保存在本机；“聊聊这个”只填入输入框，点击发送才会交给 AI。

AI：在设置中填写你自己的 API Key，点击“测试连接”，再保存。测试和聊天可能收费；本地活动不调用接口。使用自定义服务时请核对模型和接口协议，所有“兼容”服务并非都经过验证。应用不会自动重试或切换服务。费用以服务商账单为准。

数据位置：`%LOCALAPPDATA%\Forme`。设置支持导出、按类别导入、删除记录和清除全部数据。导出不包含密钥，但可能有私人文字；普通记录未额外加密。详见 [隐私说明](隐私说明.md)。

首版导入支持不超过 32MB 的数据文件；更大的导出文件可以保留，但暂时不能直接导回。

升级前先从托盘退出应用，再运行新版安装包。卸载保留个人数据，如需清除请先在设置中操作。

0.1.0 为初版可运行构建；真实 AI 服务需要通过你的密钥验证，完整设备兼容及长时间稳定性验收见项目验证记录。不将模拟服务测试视作真实服务可用性承诺。
