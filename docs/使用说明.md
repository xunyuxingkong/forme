# 欢迎来到 Forme

双击同目录的 `Forme.exe` 可免安装运行。安装版可以从桌面或开始菜单打开。需要 Windows 11 x64；运行时已包含，无需安装开发工具。

首次启动可以给伙伴起名，AI 连接可跳过。

0.2 版本可在“设置 → 伙伴模型与资源占用”选择芽芽伙伴、小猫、小狐狸或企鹅，点击“保存偏好”同步到小屋、桌面和放松页。省电模式降低待机与动作帧率；减少动效使用静态反馈。

布置页可以保存晴、雨、雪的静态天气、灯和壁炉状态，并通过文字按钮使用场景互动。室内可点击书架读书、鱼缸看鱼、零食碗喂食、睡垫休息，以及切换灯和壁炉；户外可到池塘木桥、野餐毯、凉亭和风铃旁互动。伙伴会先移动到可到达的位置，后续点击替换当前目标。天气不会启动持续粒子动画。

- 点击小屋或户外的空地，伙伴会移动到那里：短路径行走，超过3米的路径奔跑；再点击会改换目的地，家具、树木和边界会限制路径。拖动仍用于旋转视角。
- 场景右上角可切换“去户外 / 回到小屋”。室内约8.7m × 7.3m，户外草地20m × 20m，滚轮可放大查看伙伴。场景和位置在本次窗口中临时保存，切换场景回到入口，不写入个人记录。
- 3D 小屋：拖动调整视角，滚轮调整远近，点击“复位视角”恢复。小窗口中点击“查看3D小屋 / 返回活动”切换。
- 点击伙伴聊天、书桌专注、心情本记录、沙发放松、植物浇水。底部按钮可以进入同样的活动。
- 关闭小屋后伙伴回到桌面。拖动移动，点击打开快捷入口，右键设置置顶、安静或收起。
- 桌面悬浮时，快捷面板的“聊天”或右键“聊一会儿”打开宠物旁的小聊天窗口，宠物留在桌面，随机走动暂停。可输入、发送、停止、新建对话；关闭后保留会话和本次运行的草稿，并停止尚未结束的回复。“完整聊天”进入小屋聊天页，保留草稿及正在进行的回复；历史会话管理仍在完整聊天中。“AI设置”打开小屋设置。
- 桌面伙伴的快捷面板或右键菜单可选择“原地待机、睡觉、随机走动、随机奔跑”，选择会保存在本机。走动和奔跑限定在当前屏幕的工作区内，避开任务栏；打开面板、拖动、专注、AI处理中或安静模式会暂停移动。面板闲置8秒关闭后恢复，减少动效时不自动移动。
- 动作列表可执行轻轻跳跃、揉揉、摇摆舞、蹦跳舞、转圈舞，以及吃零食、读书、趴下休息和观察。舞蹈每次约6秒，再执行会替换当前动作，“停止动作”立即回到所选待机状态。动作期间暂停随机移动；睡觉显示闭眼休息与轻微呼吸。全部在本地执行，不调用AI接口。
- 伙伴会轻轻呼吸、转头和眨眼；点击会轻跳，拖起和放下有动作反馈，放松页可揉揉。安静模式暂停自动动作，主动点击仍会回应；设置中的“减少动效”使用静态表情反馈。收起、隐藏、最小化、锁屏和睡眠时停止宠物动画和移动，恢复后需重新点击目的地；减少动效时点击空地会直接到达合法目标。
- 托盘中可以打开小屋、显示伙伴、收起或退出。关闭小屋并不退出程序。
- 专注和休息均需主动开始，锁屏、睡眠或退出时会暂停；恢复后可继续。
- 未开始的专注任务和时长在本次运行中保留，切换页面或设置不会清空；退出程序后清除，不会自动发送给 AI。
- 揉揉伙伴、戳泡泡和呼吸节奏无需联网。植物每天可浇水一次，不会枯萎。
- 花园中标注“成长盆栽”的植物会随浇水成长；花坛及灌木属于装饰。
- 心情保存在本机；“聊聊这个”只填入输入框，点击发送才会交给 AI。

AI：在设置中填写你自己的 API Key，点击“测试连接”，再保存。测试和聊天可能收费；本地活动不调用接口。使用自定义服务时请核对模型和接口协议，所有“兼容”服务并非都经过验证。应用不会自动重试或切换服务。费用以服务商账单为准。

硅基流动：在小屋的“设置 → AI连接 → 服务预设”选择“硅基流动 · DeepSeek”，自动填入 `https://api.siliconflow.cn/v1` 和 `deepseek-ai/DeepSeek-V3.2`。填写硅基流动平台的API Key（不是DeepSeek官方密钥），测试成功后点击“保存 AI 配置”，再到聊天页发送。预设采用非思考模式，兼顾陪伴聊天的成本和首字延迟；不保证服务端响应时间。高级设置可修改模型名称，但其他模型的参数兼容及权限需自行测试。模型与价格以硅基流动控制台为准。选择预设不会保存配置或发起请求；测试新地址须填写该服务的密钥，避免自动向新服务发送旧密钥。

数据位置：`%LOCALAPPDATA%\Forme`。设置支持导出、按类别导入、删除记录和清除全部数据。导出不包含密钥，但可能有私人文字；普通记录未额外加密。详见 [隐私说明](隐私说明.md)。

角色与记忆：设置中的“伙伴角色、记忆与动作权限”提供4类角色预设、角色背景、语气、输出上限和上下文预算。聊天页可以搜索当前会话、重命名会话并编辑最多800字的摘要。“存为记忆”只填入记忆编辑框，补充标题后保存；记忆最多30条，每条400字，可编辑、停用或删除。分享开关默认关闭，开启后只把当前服务商绑定且启用的确认内容按预算发出，切换服务商不会自动分享。发送预览显示实际将分享的内容。

AI 动作：宠物和场景两个权限默认关闭。主动开启后，可以发送“跳一支摇摆舞”“去户外，再下雪”“关掉灯”“走到 X=2、Z=3”。完整回复中的白名单命令才会执行，动作结果写在回复下方；不执行任意代码、文件/系统操作、记忆写入或购买。只有文字回复而没有有效命令时，不会改变场景。坐标移动需要可见的小屋，场景切换会打开小屋。停止、中断、截断和已关闭权限的回复不执行动作。

聊天和确认记忆保存在本机。若写盘失败，回复会提示暂存于内存，可复制、重试保存或明确放弃；退出前应处理暂存内容。导入聊天备份会替换记忆与摘要，并关闭分享开关，需重新开启。删除会话会删除摘要；长期记忆独立管理。“清空聊天”包括记忆和摘要。

导入与导出共用 512MB、一百万条记录的安全上限。超过上限时不会覆盖原数据或已有导出文件，可分类别导出。导入先在后台逐条检查，确认后才替换所选类别；可取消检查，也可在设置中从恢复备份恢复。

升级前先从托盘退出应用，再运行新版安装包。卸载保留个人数据，如需清除请先在设置中操作。

0.3.0 新增“雨天纸船”样板。从底部“玩纸船”进入池塘，先选船形、颜色与风向，再拖动三片叶子改变导流路线；按钮也可移动和旋转叶子。虚线即时预览路线，Ctrl+Z撤销布置，Esc取消拖拽或捞回船。点击放船，伙伴沿岸陪伴，船会抵达柳树、木桥或睡莲码头；经过粉色花瓣可带回额外发现。结束后命名并收藏，收藏列表可重玩、陈列和删除。最小化自动暂停，恢复后需点击继续；减少动效会直接显示旅行结果。窄窗口上下显示场景和可滚动操作区。船形与水流会改变路线，颜色只影响外观。

此次为升级方案A阶段的首批可玩样板，尚未完成后续全部玩法、模型与场景重制。真实AI服务需要通过你的密钥验证，完整设备兼容及长时间稳定性验收见项目验证记录。

0.4.0：从“玩耍与生活”进入新玩法；“布置→进入家具编辑”可拖动书架、暖灯、零食碗、小窝、鱼缸和坐垫。位置按0.25m吸附，侧栏支持旋转、复制、收纳、撤销和阅读角模板。预览显示重叠或通道问题，检查通过才能点击保存；切换页面会取消未保存草稿。

家具位置与天气、昼夜、灯光会开放8种生活事件，在生活页点击体验，发现进入本地图鉴。藏物页支持你藏伙伴找、伙伴藏你找，点击家具或从侧栏选择检查；位置线索来自当前摆放，随时可结束。拿起小球后按Shift拖动预览落点和抛物线，松开投掷；也可以使用方向按钮，伙伴落地后再去捡。

悬停可操作物件显示高亮框，右键打开更多动作。顶部“伙伴控制”可随时叫回或停止，“收起侧栏”展开场景；窄窗口上下显示场景和操作，极小窗口用“查看3D小屋/返回活动”切换。减少动效直接完成投球落地；最小化会取消抛球和藏物活动。图鉴可单独重置，小屋导出包含布局与发现。

0.4局部精修芽芽的叶耳与身体、小猫的耳朵与尾巴。完整四角色/场景重制仍在后续阶段；性能专项测试后置，模拟缩放验证不代表真实多屏设备全部兼容。详见[0.4功能与玩法升级记录](0.4功能与玩法升级记录.md)。

0.5.0 AI共同创作：在“设置→伙伴角色、记忆与动作权限”启用并保存“玩法调用”和／或“家具预览”，然后聊天。试试“帮我布置阅读角，先给我预览”“体验当前能发生的阅读事件”“让伙伴藏，我来找”“把纸船变成粉色，风吹向柳树，再放船”。模型切换属于宠物权限，天气和灯光属于场景权限，分别启用需要的项。

每次最多3步，移动和短动作会等待完成，整组最多30秒；聊天“停止”、伙伴控制“停止当前活动”或桌宠“停止动作”可中止。纸船和藏物独立运行，不会自动调用AI。阅读角模板替换为基础6件家具草稿，家具移动／旋转先检查通道，只预览；点击“保存家具布置”才保存，撤销或离开可取消。纸船名字只修改当前完成旅行，点击收藏才保存。联网返回的指令可能因条件或权限被拒绝，真实结果在回复下方。若提示预算不足，可减少控制权限、缩短角色设定或提高预算。详见[0.5AI共同创作与验证记录](0.5AI共同创作与验证记录.md)。

0.5.1：日常对话无需填写坐标。开启宠物动作权限并打开小屋，可说“你能走两步吗”“跑几步看看”“过来一下”“去书架旁边”“去窗边”“跳个舞”。AI选择语义动作，本机根据当前位置、家具与通道选择目标，走／跑一小段后停下；“去书架旁”只移动，不自动开始读书。否定、引用和讨论动作不应触发执行。桌面悬浮支持原有舞蹈与随机走动待机，小屋的短途／物件移动不会自动打开小屋。动作生成仍受所配AI模型影响，以回复下方的本地反馈为准。

0.5.2：悬浮聊天也支持短途走／跑、睡觉、舞蹈和随机模式。先开启对应权限，再说“你能走两步吗”“随机走动”“别动”“陪我玩藏物”；需要场景时打开相应小屋页面。设置中的“自然动作规则 · 可编辑”可修改 `interaction-rules.json`，匹配明确短句后直接本地执行，无需密钥、不联网；未匹配则使用AI。支持“走两步，然后跳个舞”，最多3步、30秒；发送预览显示实际路径，本地记录不会加入AI历史。详见[0.5.2悬浮动作与本地规则](0.5.2悬浮动作与本地规则.md)。

0.5.3：聊天伙伴以屏幕宠物作为应用内的虚拟身体，不再用‘没有身体’拒绝动作，也不以文字表演代替执行。‘转一圈看看’支持本地转圈；未修改的旧默认规则自动升级，自定义规则保留，可在转圈规则中添加‘转一圈’等表达。先开启宠物动作权限，以程序动作反馈为准。

0.5.4：主页可以隐藏或重新显示左侧3D场景，选择会保存在本机设置。设置页提供六种软件窗口背景色预设，也支持输入 #RRGGBB 自定义颜色；卡片与3D场景保持各自配色。
0.5.5：新增屏幕工作区环绕跑步。可以说“整个屏幕跑2圈”或“绕屏幕跑两圈”；规则优先时直接本地执行，结束后停下。动作按当前显示器的可用工作区四角移动，不读取或截图其它窗口；需要开启宠物动作权限。聊天会等待真实移动结果，停止、遮挡、显示器边界改变或30秒限时会中止并反馈。
0.5.6：左侧3D动画的隐藏/显示开关移到顶部工具栏，在主页、设置等页面都可见，并统一控制左侧场景区域。

0.5.7：屏幕环绕跑步支持自然请求表达，例如“你能不能让它绕着屏幕跑两圈”“可以帮我整个屏幕跑一圈”。明确的绕屏移动由本机规则直接触发，回复中的动作完成提示以实际移动结果为准；否定、引用和讨论语境不会触发。动作仍需开启宠物动作权限，最多两圈且有30秒上限，不发送聊天内容到外部服务。

## 0.6 意图识别整改

先开启需要的宠物／场景／玩法权限。可以说“去水边”“走到书柜那里”“在附近逛一下”；常见表达在本地理解，无需密钥、不联网。去池塘或书架会由程序选择场景和可达位置：跨场景同时需要场景权限；任一权限或目标预检失败，整组不执行。悬浮聊天和托盘模式也可按明确请求打开小屋。否定、引用、讨论及条件句不执行。

规则仍用于快捷命中和自定义，不必穷举所有整句话。无法在本地完整理解的动作交给AI，只发送本次输入和固定意图说明；AI返回意图，程序决定执行步骤。每次最多一个请求、三步（含场景切换）、30秒；没有合法意图时明确显示未执行，不展示模型自称成功的文字。动作完成、失败、打断和取消都以本机真实结果显示。

每日三个任务按日期确定，动作不重复、相邻日不重复；奖励规则保留。少量进阶收藏在Lv.2／3／4／7／10／15／20解锁兑换，已拥有的物品继续可用，基础动作与活动不锁。户外收藏间隔至少五分钟，连续探索仍有环境文字与伙伴回应。晨间点心只在6:00–10:59且环境条件满足时出现。
