# Forme 初版隐私说明

适用版本：0.6.0（意图整改后）。日期：2026-10-10。

0.6.1 补充（2026-10-15）：动作协议增加桌面／小屋主体标记，仍由现有白名单和权限限制执行。提醒调度移至常驻应用宿主，仅本机检查已保存的提醒，不调用模型、不上传提醒内容；关闭小屋后继续调度，彻底退出或关机后不保证提醒。窗口关闭按钮会将提醒延后十分钟，按钮“关闭”会持久化为已处理；最多同时显示五条，其余等待已有提醒处理。此更新未接入电脑控制、外部 Agent 或项目资料库。

0.6.2 项目协作补充（2026-10-15）：普通聊天附件规则保持不变。独立“项目协作”入口允许用户选择1至4份文本/DOCX，在明确勾选本项目分享并点击生成后，将所选正文、来源元信息、当前目标和该项目草稿发送到界面显示的当前服务；未选择的本机记事、其他文件和普通聊天不加入请求。不上传密钥、原路径，不自动切换服务。每个目标最多两次请求，失败/取消计次，无自动重试；沿用文字预算及输出上限。原资料仅内存保存，结束、撤回分享、期限结束或退出后清理；已经传给服务商的内容仍受其政策约束。

0.6.3 项目待办建议补充（2026-10-15）：AI 给出的待办建议先保存在项目账本，用户逐项确认后才写入本机待办列表；创建待办与项目账本的去重标记使用同一数据库事务。建议没有截止时间或提醒时间，用户可在“今日工作台”自行编辑。AI 不会因生成建议而自动创建正式待办或提醒。

本机项目账本保存目标、来源文件名/正文哈希/段落数量、状态、额度、最后请求服务与模型及必要澄清问题，不保存完整资料或原始模型请求。生成的摘要、原文短引和待办建议保存为普通记事，未额外加密；清除内存资料不删除这些产物。项目JSON导出含账本与选中草稿，不含原资料或密钥；一般工作记录导出包含草稿，不包含项目账本。删除项目记录保留笔记，笔记需另行删除；清除全部个人数据会删除两者。重启不自动恢复资料、联网许可或重放写入。此阶段未提供项目JSON自动导入或资料副本长期保存功能。

0.6.4 能力目录补充（2026-10-15）：能力目录只描述当前已有的伙伴动作、记事/待办操作与项目草稿能力，不会自行开启权限或增加本地数据读取。原动作预检、当前用户请求限制和项目逐项确认仍有效。此批未加入电脑操控或外部 Agent。

0.6.5 聊天动态能力快照（2026-10-15）：新增独立的“聊天时分享伙伴状态给当前AI”开关，默认关闭，保存后仅向绑定地址随普通文字聊天发送状态。内容为桌面/小屋视图、室内/户外场景、伙伴模型、可见与活动状态、动作权限和经过本机预检的短活动ID；活动列表可能反映当前有哪些可用物件。不会发送截图、坐标、完整布局、隐藏答案、旅行名字、共同经历或工作记录，主体标识与动作版本仅留在本机核对。此许可不继承原自主选择/合作玩法开关，带附件请求不附带状态。换地址清除这项许可；撤回会取消使用它的当前聊天请求并停止后续动作。已送达服务商的状态无法撤回；原始快照不单独写入聊天数据库，模型回复中引用的状态仍属于普通聊天记录，可能进入后续有限历史或导出。

0.6.6 跨组件目标计划（2026-10-15）：新增默认关闭的联合执行许可，允许AI按本轮明确请求给出最多三步的本地工作操作与有限伙伴动作。不会读取未分享资料，也不因开启联合执行而开启伙伴状态分享；仍为一次聊天请求，不新增后台规划请求。所用资料仍仅为原聊天允许的内容，操作结果不再发给模型。本机设置表保存原会话/消息ID、服务地址/模型、步骤能力、视图、状态、产物ID、回执代码或匹配数量及时间，不重复保存操作参数和正文。目标原消息和结果标为本地操作，不进入后续模型历史。

执行记录最多50条，可在聊天记录管理中独立导出元信息、删除；一般聊天导出只包含原消息和结果，工作记录类别包含实际记事/待办/提醒，均不包含联合执行账本。删除会话或清空聊天会删除对应执行账本，已生成的工作产物继续独立保存。替换导入聊天会清除原账本，消息的本地操作标记保留以避免重放。执行账本尚不支持自动导入或自动恢复权限。

每步先登记开始，再执行并读回产物或取得动作完成回执；工作写入与回执登记是分开的本机事务。两者之间异常退出时标记“中断，需核对”，不会误称完成或自动重放。失败或取消不自动删除已经写入的工作产物。原始模型计划和操作正文不进入执行账本或技术日志。

0.6.9 合作玩法账本与反馈规划（2026-10-15）：主动点击AI合作按钮后，本机为该局记录玩法类别、阶段、步骤、请求次数、服务地址/模型、时间与真实结果代码，与聊天联合目标共用最多50条的记录上限。不会为合作玩法创建虚构聊天消息或会话，不保存藏物答案、线索正文、候选位置正文、完整布局、私有场景/局次标识或原始请求。合作记录在藏物/纸船页面可独立查看、导出和删除；导出不自动导入。普通小屋备份不包含这些账本元信息；清理或替换导入小屋会清除原合作账本，已收藏作品按原小屋规则处理。聊天清理/替换仅清除聊天来源的联合目标；全部清理包括两类账本。重启只标记未完成记录中断，不恢复许可、建议或继续调用模型。

分享范围仍是原独立合作授权内的公开数据：藏物候选区域、实际已检查项和用户本局线索；纸船目标码头与本机模拟候选的ID/目的地，不增加工作资料或其它本地内容。藏物最多两次规划，第二次可依据本局真实检查结果调用，即使没有新增线索；改线索不重置次数，失败/取消计次，总时限120秒、单次规划25秒，无格式/网络自动重试。纸船一次建议仍限25秒、建议十分钟内有效，用户确认才应用并放船；到岸核对不调用模型。生成合作目标会清除当前资料项目的内存正文与分享许可，保留已保存草稿。分享撤回会停止在途合作请求；已发送内容仍受服务商政策约束。未开启聊天联合目标许可不妨碍单独授权的主动合作按钮。

## 本地处理

联合目标进入藏物/纸船时，本局身份、伙伴实例、布置版本和结果在本机核对；这些核对字段不进入聊天状态分享、模型请求或执行账本。账本仅增加“等待本局结果”和找到小球/实际到达码头等结果代码，不保存藏物答案、坐标或布局。等待与结果登记由已有场景事件触发，不增加模型调用或后台AI循环。当前仅支持伙伴藏好供玩家寻找，以及纸船打开/放船；主动AI搜索或合作纸船建议仍需原独立许可和按钮。退出应用后不恢复或重放本局目标；未确认结果会标为中断需核对。

“当前目标”任务卡从本机项目和目标执行记录展示原目标、来源文件名/段落数、步骤状态与产物是否存在；不新增模型请求、截图、日志或数据存储，也不把卡片内容自动加入模型上下文。收起卡片只影响本次运行的显示，不删除原记录或产物。通过卡片的“结束工作，玩藏物/玩纸船”入口会清除当前资料项目的内存正文和分享许可，保留本机草稿与记录，再打开玩法页面；不会自动开始玩法或调用合作AI。玩法仍沿用各自的独立分享许可。

3D 伙伴、小屋、植物、装饰、专注与休息、放松活动、设置和心情保存均在本机运行。应用没有账号、云同步、遥测或自动日志上传，不扫描磁盘，不截屏，不使用摄像头或麦克风，不监听剪贴板。你主动在输入框粘贴内容时，内容留在草稿中，点击发送才会分享给 AI。

记录存于 `%LOCALAPPDATA%\Forme`。聊天、心情、任务名称等普通记录未额外加密，能够访问此用户目录的人可能读取它们。API Key 单独通过 Windows DPAPI 当前用户保护保存在 `ai.secret`，不能据此声称整套数据已加密。

## 联网处理

家具布局、组合事件、藏物和抛球的规则全部本地执行。保存家具才将布局落盘；生活图鉴记录最多20个发现ID，不保存行为日志或聊天内容。藏物目标、提示和查找过程只暂存内存。布局和图鉴随“小屋”类别导出/导入，旧备份缺少该字段时保留已有记录。可以在“玩耍与生活”重置图鉴，并清理应用管理的恢复备份；家具可收纳或恢复基础摆放后保存。设置中的清除全部数据包括布局和图鉴。外部导出文件需要自行删除。

AI动作、玩法调用和家具预览权限分别默认关闭。明确的动作先在本地识别；需要AI兜底时，仅发送本次输入和固定意图说明（包括内置目标、玩法与生活事件ID），不发送聊天历史、记忆、角色设定、场景坐标、家具布局、藏物线索或旅行名字。家具和导流预览的数字仅转录本次输入中明确给出的值；程序拒绝AI猜测的坐标。AI家具操作只生成可撤销草稿，由你点击保存；旅行命名不自动收藏。每次操作最多一个AI请求，不自动重试、联网反馈、追问或续接。整组执行前检查权限和目标／路径，关闭权限立即阻止对应后续执行。

默认优先匹配本地快捷规则，再用轻量意图解析理解常见动作和目标组合，仍需对应权限。规则在用户数据目录的 `interaction-rules.json` 中，可在设置查看、编辑、关闭或恢复默认。命中的消息和动作反馈标为本地，不调用AI，也不进入后续AI历史；无法本地完整理解的动作才按已有同意流程请求AI意图识别；普通聊天走独立对话请求。规则不上传、不轮询其它文件、不含密钥；清除全部个人数据会重置规则。自定义表达可能含个人信息，复制规则JSON时请自行检查；规则不自动纳入聊天/小屋导出，本地消息则可正常导出删除。悬浮移动只使用本工具窗口坐标和显示器工作区，不读取屏幕图像或其他应用内容。

纸船路线、风向、叶片和结果均在本地计算，不调用外部服务。只有点击收藏才将纪念船名称、布局、目的地、花瓣发现、宠物形象和时间写入本地数据库，最多60条；未收藏的摆法和旅行只暂存内存，程序退出后清除。纪念船不自动进入聊天上下文或AI记忆。小屋类别的导出会包含收藏，导入该类别可替换收藏；旧备份没有收藏字段时保留现有收藏。单条删除会清理应用管理的恢复备份；你保存到其他位置的导出文件需要自行删除。

只有你点击发送、重试或测试连接时会请求配置的 AI 服务。发送的内容包括当前消息、受预算限制的当前会话历史、伙伴名字、用户称呼、角色设定和回复偏好。默认不发送长期记忆；开启记忆分享后，当前服务商绑定且启用的确认记忆和会话摘要会按预算一起发送。动作识别使用独立请求，只发送本次输入和固定意图说明；普通聊天也不自动附加场景状态。发送预览可查看实际文字。不会自动附加你的心情、专注任务或其他本地记录，不自动提取记忆或总结私人记录。

“聊聊这个”仅把选中的心情放入输入框，仍需要你点击发送。连接测试只发送固定的非个人文字。界面显示目标地址和模型，更换服务地址不会自动分享旧对话；继续旧会话前会确认上下文转移。

选择智谱官方预设只填入地址和模型，并清空尚未保存的密钥输入，不自动联网或保存。发送或测试时使用普通智谱API入口；GLM-5.3系列按用户选择的思考强度请求，推理片段只用于判断流式请求仍有进展，不显示、不写入数据库、日志或后续历史。文字请求首段60秒、总时限180秒（带附件首段90秒、总时限240秒）及用户输出上限仍有效。PNG/JPEG以图片内容、PDF以原始文件Base64随本次发送，不额外调用文件上传、OCR、搜索或托管服务；文本与DOCX仍只发送本地提取文字。WebP在发送前本地拒绝，不自动转换。已通过自定义入口使用智谱的记忆继续沿用原服务商标识，无需迁移，不会自动发送其它平台的记忆。

硅基流动的已适配GLM文字请求按所选档位发送思考预算，预算为平台提示值，不保证硬限制账单。GLM连接测试采用用户已保存的正文上限，测试发送固定文字，不含聊天历史、记忆或附件。推理内容仅更新停滞计时，不显示、保存或回传；文字请求首段60秒、总时限180秒（带附件首段90秒、总时限240秒）与手动停止仍有效。没有自动重试或增加用户输出额度，不改变硅基其它模型参数或附件分享范围。

服务商会收到请求和网络连接所需的信息，其留存及计费政策由服务商决定。停止请求只能取消本地传输，不保证服务端停止处理或退还已经发生的费用。Forme 不自动跟随重定向转发凭据，也不自动加载回复中的远程图片或网页；回复按纯文本显示。

“项目协作”的“读取指定网页”由你主动提供一个公开 HTTP(S) 地址后触发。Forme 使用不带浏览器Cookie、登录状态、AI密钥或自定义请求头的直连 GET；目标网站会收到该次请求及正常网络连接信息。只接受公网 DNS/IP 目标，逐跳检查最多4次重定向；最多读取1 MB、等待20秒，不执行页面脚本，不点击、不提交表单，也不重试。仅提取静态HTML正文，最多4份来源保存在本项目内存；120秒期限从首次生成草稿起计算，未生成前在结束项目、撤回分享或退出时清除。项目正文不会因读取网页而自动发给AI；只有勾选本项目的分享许可并点击生成时，所选网页正文、标题/来源信息和目标才发送给当前服务商，仍受现有上下文预算限制。账本保存来源标题、哈希及移除查询参数与片段的网页地址，不保存网页全文；结束项目、撤回分享或到期会清除内存正文。网络请求直连且不使用系统代理，要求代理的网络可能无法读取。当前不支持需要登录、依赖脚本渲染或超出大小/时间限制的页面。

项目页的“保存草稿为文件”只在用户选择目标路径后写出现有草稿正文和引用。写入在所选目录中短暂创建临时文件后原子替换目标，并回读核对；临时文件在失败时清理。保存位置不上传、不保存在项目记录中，也不会导出原始资料、密钥或任务账本。覆盖现有文件前由系统保存对话框确认。

0.6.13起，指定网页读取在随Forme打包的可信只读工具进程中执行，通过标准输入/输出的MCP协议返回来源；不开放网络监听端口或任意工具进程配置。用户地址通过进程间管道传递，不放进命令行或日志。工具在创建WPF窗口、数据库、密钥存储和后台服务之前进入专用模式，只具有一个网页读取接口。父进程仅转交系统/临时目录和.NET运行时所需环境项，不继承密钥、代理、用户目录和自定义环境变量。工具进程限制256 MB提交内存、一个进程、最长30秒自结束；宿主仍按20秒读取期限和用户停止回收进程，只有确认进程退出后才接受来源。上述Windows Job限制生命周期和资源，不构成对任意第三方代码的文件系统/网络权限沙箱；当前只启动本应用内置且经过核对的工具，不加载第三方Agent。静态网页仍遵守已有公网地址、逐跳重定向和1 MB限制；向模型发送仍由本项目明确分享和生成操作触发。

选择“硅基流动 · DeepSeek”预设并保存后，聊天请求发送至 `https://api.siliconflow.cn/v1`，由硅基流动提供DeepSeek模型服务。使用硅基流动账户的密钥；预设切换仅填写表单，不联网、不保存、不分享旧会话。切换服务商时必须填写该服务商的密钥，旧密钥不会发给新服务。记忆绑定服务商，复制到新服务需要用户主动检查保存。不自动获取模型列表、余额或其他账户信息。

AI 动作权限默认关闭。开启后也只允许有限的本机宠物/场景动作，不能执行系统命令、访问文件或屏幕、写入记忆、删除记录或自动购买。每轮最多3个经过白名单校验的命令，停止、中断、截断或未获授权的回复不执行动作。命令协议不保留在聊天正文，实际本地动作结果保存在回复下方。

户外发现的五分钟冷却时间戳保存在本地数据库普通设置中，重启后继续有效，不上传、不纳入记录导出；清除全部个人数据会删除它。环境反馈仅在你主动探索时本地生成，不保存新的行为日志。

## 导出、导入与删除

可在完整或悬浮聊天主动添加图片、PDF、文本及DOCX。选择、读取、预览和移除均在本地进行，点击发送才将所选附件传给当前服务。图片以及服务支持的PDF按原文件发送，可能包含内部元数据；DeepSeek官方的PDF按下文转换为页面图片。文本及DOCX仅发送提取文字，DOCX不含内嵌图片、批注或页眉页脚。每次最多4个、原文件单个5 MB、合计10 MB，转换后的图片同样受总大小限制；文字最多64 KB并受文字预算限制。图片/PDF用量由服务商另计，不包含在文字预算内。

DeepSeek官方接口使用图片输入，因此PDF在本地转换为全部页面图片后发送，不发送原PDF文件。最多4页，可逐页预览；超页、转换失败或超限整份不添加。转换在独立隐藏进程内通过内存管道进行，不读聊天数据库或密钥，不联网、不将用户PDF和转换页落盘；转换进程限制256 MB提交内存，停止或30秒超时会终止该进程，父进程退出时也回收。转换图片同样只随本次消息发送，不进入后续历史；若添加原始PDF后切换为DeepSeek，需重新添加完成本地转换。其他服务仍按其文件格式发送PDF原文件。

原附件和提取文字只暂存在内存，数据库保存用户输入、文件名标记和AI回复；回复引用的文件内容仍属于聊天记录，可能进入导出或后续文字历史。原附件不存诊断、记忆或导出，不自动重传。失败或取消后只缓存最后一轮用于本进程内手动重试，成功、下一条新消息、换会话、清除或退出时释放；重启需重新添加。移除不删除原文件。带附件消息不执行宠物动作。PDF需服务商接受文件消息格式，失败不会自动转换或重试。

聊天正文和复制记录隐藏应用生成的附件保存/重传说明，仅在附件消息类型及已知末尾格式同时匹配时处理，不删除用户自己输入的类似文字。原始文件名标记仍在本机记录、备份和导出中，历史上下文与重试规则不改变。服务失败提示保留在操作状态，新动作识别请求的网络诊断不再存作宠物回应；已有记录中完全匹配的已知服务诊断也仅在显示时隐藏，真实模型文字和部分回复保持原有保存方式。必要错误、权限拒绝、截断、停止及实际动作结果仍能在相关状态或正文查看。

导出包含你选择的记录类别；聊天类别包括长期记忆和会话摘要，房间类别包括模型和氛围配置。不包含密钥、AI 接口/角色设置或诊断日志。导出文件可能包含私人内容，请自行管理保存位置和副本。

导入需要明确确认，并且只替换文件包含的类别，不覆盖密钥。导入聊天时会替换该类别的记忆和摘要，同时关闭记忆分享，需重新开启。替换前的恢复备份保存在数据目录 `recovery.json`；下次成功替换时更新，也可主动删除。该备份同样可能包含私人内容。

删除会话会同时删除该会话的摘要；用户主动保存的长期记忆独立保留，可逐条删除。“清空聊天”会清空全部会话、消息、记忆与摘要。磁盘写入失败时，回复可能暂存于进程内存；界面提供复制、重试保存与放弃入口，退出前应处理暂存回复。

升级数据库结构前，应用在同一数据目录保存 `migration-v*.db` 备份，可能包含升级前的私人记录和普通设置，不含单独保存的 API Key。设置中的“删除应用恢复备份”同时清理导入和升级备份；删除记录和清除个人数据也会清理这些备份。

大文件导入先逐条解析到 `%TEMP%\Forme-transfer` 下的临时数据库，确认前不修改原记录。临时内容未加密，可能包含所选私人记录；正常完成、取消和失败时删除。异常终止留下的临时目录在后续启动时清理，活动中的导入目录由文件锁保护，不会被其他应用实例清理。该目录仅供本应用数据转换使用，不扫描其他临时文件或磁盘内容。

删除记录会清理含有该内容的应用管理备份，防止导入后恢复已删除内容。清除全部个人数据会清空记录、房间、偏好、恢复备份与凭据，不触及用户自行保存在其他位置的文件。此操作是应用层删除，不承诺取证级擦除，也无法删除第三方服务已留存的内容。

卸载保留个人数据。如果希望移除这些内容，请先在应用设置中清除全部个人数据，再卸载。开发测试使用 `artifacts` 下的隔离数据，与正式用户数据分开。

## 权限与维护

开机启动默认关闭，仅在你启用后创建当前用户的启动快捷方式。安装和卸载只管理本应用的安装目录、快捷方式及当前用户卸载入口，不需要管理员权限。首版更新由用户手动下载安装包，不后台检查或下载更新。

异常诊断仅存本机数据目录的 diagnostics 子目录，最多保留10份，包含时间、错误类型、HResult、程序集版本和方法名；不记录异常消息、文件路径、聊天、密钥或网络响应，不自动上传。未知异常会暂停并退出，可预期的文件/网络/输入错误在操作处提示。

导出也会在 Forme-transfer 的独立临时目录中生成本机数据库快照，快照含本机记录，不包含独立DPAPI密钥文件；完成或失败后删除，异常退出遗留由下次启动清理。


## 自主选择的游戏状态分享

“分享游戏状态给当前 AI”默认关闭，保存后仅用于用户主动点击“自主选择”的请求，不发起后台调用。每次发送本次目标和当前目标视图、场景、模型、天气、灯光、活动状态、经本机检查可用的短活动及其固定说明；可用活动可能反映当前有哪些物件和通路。不会发送家具坐标、隐藏答案、桌面截图、其他窗口、剪贴板、文件目录、聊天历史、角色背景、记忆、附件、记事或待办正文。

此分享开关与已保存的服务地址绑定。换服务后不能沿用旧地址的分享许可，需重新开启保存。自主选择按钮的右键菜单提供独立发送预览；普通聊天的发送预览不代表自主选择请求。

原始状态快照和模型选择协议仅在本次请求内存中使用，不写入聊天或诊断日志；本机聊天保存用户目标、模型提供的选择理由及真实执行结果，仍可能包含用户私人文字，可通过聊天管理删除和导出。自主选择记录不自动进入后续普通聊天上下文。每次至多调用一次，停止不保证服务商停止计费，删除本机记录不能删除服务商已收到的数据。

“伙伴生活”中的后台自主默认关闭。你须先明确开启游戏状态分享、保存需要的动作权限，并点击“验证并启用”；验证请求可能收费。仅当当前服务在15秒内返回合法选择后才启用。后台每分钟最多检查一次，但新活动至少间隔10分钟、最多6次/小时且遵守你设置的滚动24小时额度；取消和失败也计数，连续失败会暂停。伙伴隐藏、安静模式、专注、系统挂起或小屋聊天正在使用时不发起请求。后台不读取聊天历史、附件、记事或待办，不自动改设置或保存房间；用户操作会取消后台请求并优先处理。服务商收到的游戏状态仍受“分享游戏状态”开关和已绑定的服务地址控制。

共同经历默认不记录；开启后最多保留200条，可逐条停用或删除。只有另外开启“让AI参考游戏经历、偏好与示范组合”时，活动选择请求才会附带最近4条已启用的游戏结果、偏好和当前场景可重放的示范组合。示范动作先在本机实际执行，最多3步；保存后本机重放不联网。删除记录会清理应用管理备份，但不能删除旧聊天中已经出现的文字或服务商留存的数据。房间类别的导出可包含共同经历、偏好和示范组合；导入这类数据会关闭游戏状态分享、自主生活和经历分享，需由你重新启用。调用额度是频率上限，不是费用硬上限。

AI合作藏物与AI纸船建议默认关闭。开启“游戏状态分享”“合作玩法状态分享”，并授予玩法权限后，只有你在小屋藏物页或纸船页主动点击合作按钮时才会向当前AI服务发送本局所需信息：藏物发送候选家具的相对区域、已检查项和你输入的线索；纸船发送目标码头、当前叶片布局与本机模拟的候选结果。藏物答案保留在本机，由本机裁判；AI纸船只提供方案，须由你确认后才会实际放船。关闭任一分享开关或玩法权限后不能发起合作请求。服务商收到的数据可能按其政策保留，删除本机数据不能删除服务商已收到的内容。
