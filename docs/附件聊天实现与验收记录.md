# 附件聊天实现与验收记录

日期：2026-10-11；2026-10-12补充DeepSeek适配。工程目录：`D:\forme`。范围为用户指定的图片、PDF、文本与Word上传，不包含跨应用控制。

## 行为与限制

- 完整聊天和悬浮聊天的“添加附件”打开本机文件选择器；选择后在内存中读取快照，预览或移除均不联网。两个窗口共享当前草稿，点击发送才分享给当前配置服务。
- PNG、JPEG、WebP以`image_url`数据URL发送；支持文件消息的服务接收PDF原文件；DeepSeek官方则接收本地转换的全部PDF页面图片。沿用Chat Completions接口，不使用额外Files上传、远程文件ID或后台联网服务。通用协议依据[图片协议](https://developers.openai.com/api/docs/guides/images-vision?api-mode=chat)和[文件协议](https://developers.openai.com/api/docs/guides/file-inputs)。
- TXT、MD、CSV、JSON、日志及常见代码文本本地读取；DOCX提取正文段落与表格文字，不包含内嵌图片、批注或页眉页脚。旧DOC需另存为DOCX/PDF。无OCR或外部解析服务；DeepSeek PDF适配新增Windows SDK的.NET投影，使用操作系统自带渲染器。
- 单个最多5 MB，每次最多4个、总计10 MB；文本／DOCX文字最多64 KB。无静默截断，超限或任一文件失败时整批不加入草稿。后台读取，可停止。
- 文字受上下文预算控制，默认4096字节不变；新增16384、32768、65536可选预算用于文件文字，需手动选择。图片/PDF的模型用量不纳入文字字节估算，服务商仍可能按图像、页数或token计费。文件大小限制不等于费用上限，也不保证所有模型的上下文都能容纳。
- 带附件时固定走普通聊天，跳过本地动作规则和AI动作识别；附件内指令不能执行宠物或系统操作。
- 发送预览显示实际文字、附件名称、大小与发送方式，不显示Base64。PNG/JPEG有图片预览，DeepSeek转换后的PDF可逐页预览；其他服务的原始PDF及WebP显示发送说明。

## 隐私与恢复

原文件及提取文字只暂存在内存，不复制进用户数据目录，不存入数据库、诊断、长期记忆或导出。聊天记录只保留用户输入、附件文件名标记和回复；AI回复可能引用文件内容，这些引用属于聊天记录并可能进入后续文字历史。导出包含这些记录，需要自行管理。文件名也可能含个人信息。

原附件只随本次消息发送，不自动进入后续历史。失败／取消后仅在当前进程缓存最后一轮，手动重试使用同一快照；成功、下一条新消息、换会话、清除数据或退出后释放。重启后明确要求重新选择，不偷偷只重试文字。移除附件不删除原文件。

导出协议升级为7以区分新的attachment消息标记，SQLite结构不变；继续接受1至6旧备份。旧客户端不应导入版本7。密钥保护、服务地址校验、不跟随重定向、超时和取消维持原机制。服务拒绝附件时说明兼容条件，不自动转换、重传或切换模型。

## 兼容性与验证

图片识别需要当前模型支持图像；PDF另外要求服务商接受Chat Completions的file格式，仅“模型多模态”不能保证PDF兼容。保留用户服务和模型，不自动读取密钥进行付费测试。

### 2026-10-12 DeepSeek官方PDF适配

根据[DeepSeek图像理解](https://api-docs.deepseek.com/zh-cn/guides/vision/)及[Chat Completions接口](https://api-docs.deepseek.com/api/create-chat-completion/)，图像使用image_url格式，file块用于图片，不能直接套用OpenAI的PDF格式。[官方模型说明](https://api-docs.deepseek.com/api/responses)目前推荐deepseek-flash；deepseek-v4-flash旧名称仍接受，由最新Flash承接。实现及验收保留用户指定的deepseek-v4-flash，不自动修改已保存模型、地址或凭据。

服务主机为api.deepseek.com时，添加PDF会通过[Windows PdfDocument](https://learn.microsoft.com/en-us/uwp/api/windows.data.pdf.pdfdocument.loadfromstreamasync)和[页面渲染接口](https://learn.microsoft.com/en-us/uwp/api/windows.data.pdf.pdfpage.rendertostreamasync)将全部页面转换为PNG。最多4页，每页长边不超过1536像素，不放大超过原页面2倍；原文件单个5 MB，总附件大小以及转换页合计仍受10 MB限制。超页／超限整份拒绝，不能只发送前几页；转换不保证细小文字或图像均能被模型正确识别。

转换在单独隐藏进程中进行，输入输出经内存管道传输，不将用户文件或转换页落盘。进程不打开本应用用户数据库、读取密钥或发起网络请求，只返回页面数据或固定错误码；不继承通用环境变量中的凭据。Windows Job约束单个转换进程最多256 MB提交内存、不得派生子进程，父进程退出时回收。取消或30秒超时终止转换进程，避免渲染器不响应取消时堵住主界面。此内存限制不是整个系统或GPU的资源保证。

应用目标框架指定Windows SDK版本以调用系统API，构建与验证脚本从项目读取实际框架目录；运行时依赖由已固定的.NET SDK解析。打包包含Windows SDK .NET投影与WinRT.Runtime，许可说明同步加入。系统渲染器不随应用分发。安装包大小和转换进程启动开销会增加；没有增加闲时轮询、常驻转换进程或付费转换服务。
