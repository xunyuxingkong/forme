# 0.3 玩法升级与验证记录

日期：2026-10-10。版本：0.3.0。范围：升级方案A阶段的首批“雨天纸船”可玩样板。

## 已交付的循环

从小屋底部“玩纸船”进入池塘近景，选择轻快/稳当两种船形、三种颜色与三种风向。拖动三片叶子、用按钮旋转导流角度，路线虚线立即变化；可撤销最近20次布置，Esc取消拖拽或捞回船。放船后伙伴赶往岸边、伸手放船并沿岸陪伴，抵达后欢呼。船形影响速度与抗风，风和叶片影响目的地；颜色只影响外观。

柳树、木桥与睡莲三码头提供不同结果。经过粉色花瓣会产生额外发现。用户可为旅行命名，主动收藏完整摆法与结果、重玩或陈列到室内；点击陈列船可回到玩法。没有签到、体力、失败惩罚或后台奖励循环。

窄窗口上下显示场景和滚动操作区。拖拽有按钮替代；最小化或系统暂停后自动暂停，恢复需手动继续。减少动效直接显示相同计算结果。离开玩法停止计时器、移动和临时场景。主动点击地面优先于沿岸自动陪伴，会捞回当前船再移动。

## 模型、场景与架构

纸船、叶片、三码头、花瓣、路线和简化雨线使用本地冻结几何；近景复用现有户外池塘。雨线为静态装饰，不启动粒子系统或改变持久天气设置。船的运行只修改变换；路线预览只在布置改变时重建。芽芽与小猫增加独立手部变换，动作语义通过Reach连接模型，放船和欢呼仍由Core输出；狐狸与企鹅使用身体动作降级。

纯Core固定步长模拟不引用WPF或具体宠物，预览与实际运行使用相同规则。游戏20Hz，省电10Hz，仅活动时启动；隐藏或暂停停止。停止和完成有明确条件，无无限后台循环。收藏上限60、撤销上限20、共享纸船网格缓存6种组合，沿岸目标每秒最多更新一次。

这是局部可玩性与动作升级，尚未完成全套高质量模型、骨骼动画、材质和资产导入管线。完整模型重制、第二种玩法、自由布置关联事件、伙伴个性差异及B–E阶段仍依方案推进，不能把程序测试通过等同于玩家愿意重复游玩。

## 成本、延迟、隐私与维护取舍

游戏、预测、收藏和重玩均无AI请求、没有接口费用，不依赖联网。基础反馈由本地事件即时触发，不等待聊天请求。没有增加自动记忆总结或游戏事件上传；AI控制权限及现有发送预览保持原边界。

只有主动收藏才落盘，未收藏数据暂存内存。收藏为现有本地SQLite设置项中的有界JSON，普通数据未额外加密；包括名字、布局、目的地、花瓣、宠物形象和时间。查看、命名、删除、陈列入口在玩法页，导出/导入在设置页。删除单条清理应用管理的恢复备份，不删除用户外部导出文件。

备份格式升至4；接受1–4版本，小屋类别包含收藏。旧备份缺少收藏字段时保留当前收藏；格式4中有收藏时导入小屋类别会替换收藏。SQLite仍为现有版本4，没有新增数据库迁移。输入、数量与重复ID均先验证；复用原有导入事务和恢复机制。
