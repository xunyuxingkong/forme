# P1 纸船中断后的本机局次核对

日期：2026-10-20。版本：0.6.18。

## 本批范围

纸船可能已在场景中到岸，但应用在目标账本记录结果前退出。此前局次标识只在内存里，启动恢复只能把目标标为不确定，无法证明它对应哪一局。

每个纸船完成结果现在会在本机保存随机局次 ID、实际码头和完成时间，最多保留最近 50 条。AI 等待纸船结果时，账本把当前本机局次 ID 附在等待证据上。重启恢复后，只有目标处于中断、最后一步为不确定的 StartPlay、前序步骤全部完成，且该步骤中的局次 ID 与已保存回执完全相同，才显示“核对并确认纸船本局已到岸”。

人工确认在 SQLite 事务里把最后一步和目标标记完成、写入实际到岸码头，并移除这条回执。它不恢复游戏进程、不再次放船、不重新调用模型，也不执行任何工作步骤。没有匹配局次、无效码头或重复确认均不会更改目标。藏物的隐藏答案和局次不进入本批。

## 边界

本机只保留最近 50 条纸船结果；超出后更旧且尚未核对的局次可能失去回执。只有纸船完成结果纳入本批。藏物、桌面动作和其他外部于账本 SQLite 事务的副作用尚未获得同等恢复能力；未知结果仍保持不确定，不能自动重放。
