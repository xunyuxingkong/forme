# P2 指定网页来源实施记录

版本：0.6.10  
日期：2026-10-15  
范围：项目协作中的单个公开网页静态读取

## 已实现

- 项目页新增网页地址输入和“读取指定网页”操作；网页可以和文本/DOCX资料组成一个项目，最多4份来源。
- 本机只发送不含浏览器Cookie、登录状态、Forme AI密钥或自定义请求头的 HTTP(S) GET。只读取静态 HTML，不执行脚本、点击控件、提交表单或自动重试。
- 限制公网目标、逐跳校验最多4次重定向、总时限20秒和读取上限1 MB。DNS解析出的地址在实际套接字连接时再次校验并直连，防止检查与连接之间的DNS变化。系统代理不使用；需要代理的网络可能无法读取。
- 本机提取标题及正文段落，来源编号和引用哈希纳入现有项目资料协议。AI不能通过网页正文获得额外权限；只在用户重新勾选当前项目分享并主动生成后，所选正文才发给当前模型。草稿引用显示标题、段落、哈希及来源地址。
- 原始查询参数和片段只用于本次请求，不写入来源账本；账本仍只存摘要元数据，全文仅在当前项目内存保留。停止、结束、分享撤回、120秒到期按现有项目生命周期清除内存全文。
- 网页读取期间禁止并发启动项目文件读取、生成或发送预览；“结束并清除资料”可取消在途读取。

## 取舍和限制

本批先用受限 HTTP 读取验证“用户选来源 → 本机提取 → 明确授权 → 有来源草稿”的闭环，没有加入浏览器运行时，也没有把 Playwright MCP 的 Node/浏览器依赖带进安装包。动态页面、登录态页面、需要执行脚本的内容、非 HTML 响应、超过1 MB或20秒的响应不支持。

该实现是 P2 的只读来源切片，不是外部 Agent，也不是方案要求的 MCP/Playwright 浏览器联调；没有打开已登录浏览器、跨应用操作或电脑输入能力。下一步仍需先做 MCP 子进程的环境隔离/生命周期与取消协议，再在独立浏览器配置中验证指定页面，不应直接复用用户浏览器配置。

## 成本、延迟、隐私和可用性

网页读取本身不调用 AI、不产生模型费用；只有之后用户明确生成项目草稿时才产生一次既有项目模型请求，并受项目调用次数和上下文预算约束。读取操作最多20秒且可取消，页面超限不自动重试。目标网站会看到用户主动请求网页的网络信息。当前不使用系统代理，网络限制环境下可能失败；离线时现有本地资料项目仍可用。
