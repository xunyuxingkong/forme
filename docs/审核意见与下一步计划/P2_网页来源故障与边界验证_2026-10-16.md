# P2 网页来源故障与边界验证

版本：0.6.12。日期：2026-10-16。

## 修复

网页读取此前直接抛出 `HttpRequestException`，但界面的可预期错误白名单不包含此类型。连接、DNS、证书或HTTP失败可能进入全局未知异常处理并退出应用。现在在网页适配器内将网络及传输错误转换为可预期的业务错误；HTTP失败仅显示状态码，不回显响应正文、完整请求地址或内层异常。保留原项目资料，不自动重试，不发起模型请求。

网页请求显式禁用Cookie，继续禁用代理和自动重定向；实际连接仍经公网IP检查与DNS结果绑定。新增内部模拟传输入口复用同一套URL/重定向检查，用于离线验证，不是可配置外部工具入口。

资料期限说明按现有行为明确为：首次生成起120秒；尚未生成时资料保留在本项目内存，结束项目、撤回分享或退出清除。本批没有扩大模型共享范围。
