# P2 项目草稿文件输出实施记录

版本：0.6.11  
日期：2026-10-15  
范围：将已生成的项目草稿保存到用户选择的本机文件

## 已实现

- 项目页新增“保存草稿为文件”，仅在已有草稿时启用；通过系统保存对话框选择 Markdown 或文本文件和保存位置。
- 只写出草稿正文、待办建议/待确认信息及已有来源引用；不包含原始资料、密钥、目标账本或项目来源全文。
- 文件先写入同目录临时文件，再替换用户选择的目标；替换完成后回读并逐字节对应的 UTF-8 文本核对。失败时清理临时文件并报告，不改存到其他目录。
- 保存路径不记入项目账本，不上传到 AI 服务。覆盖目标前由系统保存对话框询问。

## 边界与后续

这一步完成 P2“文件草稿”中的用户选址与可核验输出，不是任意目录访问，也不会替模型自行挑路径或覆盖文件。它不调用模型、不改变资料分享许可。

受控浏览器仍是后续 P2 工作。当前方案尚无能限制网页跳转/页面请求内网地址的已验证网络出口沙箱；Playwright MCP 自身不构成该边界，因此本批没有启动浏览器会话或安装外部浏览器 Agent。后续需要先设计并验证浏览器进程网络隔离，再决定是否引入 MCP C# SDK 与 Playwright MCP。
