# 宠物动作与模型替换

本次实现待机呼吸、转头与眨眼、点击轻跳、揉揉挤压、拖起和落地反馈。桌面伙伴、放松页和小屋内角色共用动作系统。专注与休息只保留呼吸，角色表情由当前状态决定。动作全部本地执行，不调用 AI，不采集输入记录，不新增依赖和个人设置字段。

## 分工

- `src/Forme.Core/PetMotion.cs`：动作选择、优先级和时间采样，输出 `PetPose`。不引用 WPF、网格、骨骼或角色名字。缩放为倍率，Lift 为模型高度比例，Yaw/Lean 为角度，Blink/Expression 为语义状态。无动作时使用 `PetPose.Neutral()`。
- `src/Forme.App/PetAnimation.cs`：`PetAnimator` 管理单调时钟、帧率、可见性和资源释放。`IPetModelFactory` 创建模型，`IPetModel` 负责姿态映射和拾取归属。
- `src/Forme.App/SproutPetModel.cs`：当前角色的适配器，把标准姿态转换为该角色的变换、旋转中心与表情。
- `src/Forme.App/SproutMesh.cs`：当前角色的几何与颜色。替换角色不需要修改动作曲线。
- `Pet3DView`、`Room3DView`：场景放置、输入与生命周期；提供 `ReplaceModel(factory)`，替换时停止旧动作并释放旧模型。小屋拾取询问模型归属，不依赖固定网格或表情索引。

## 替换模型的步骤

1. 实现 `IPetModelFactory.Create()` 和 `IPetModel`。`Root` 提供模型根节点；实例之间不要共享可修改的根节点。
2. 在 `Apply(PetPose)` 中把标准姿态转换为模型自己的尺寸、朝向和旋转中心。没有骨骼的模型可以驱动整个根节点；有骨骼的模型可以映射到身体、头等部位。没有眼睛或表情能力时可忽略 Blink/Expression，身体动作仍可复用。
3. `Contains(Model3D)` 应覆盖当前可见的几何叶节点，包含表情切换后的节点。`Dispose()` 清理模型引用及自有资源，不能留下计时器。
4. 使用同一工厂注入桌面和小屋，或调用它们的 `ReplaceModel`。默认入口集中在 `SproutPetFactory.Create()`；正式更换默认角色时调整这里即可。

此接口解决动作与角色耦合，不代表已经支持任意模型文件直接导入。后续引入 glTF 等格式时，应由独立适配器处理格式加载、骨骼映射、模型居中和尺寸规范；动作控制器无需知道文件格式。也没有新增模型下载器、编辑器或桌面自动行走。

## 资源与交互边界

待机目标 15 帧/秒，显式动作目标 30 帧/秒。直接输入即时采样，计时器只驱动局部模型变换，不重建整间小屋或每帧创建几何。冻结基础网格与材质继续共享；角色表情缓存最多 12 种组合，每种表情的静态几何也被冻结，只修改根节点变换。重复输入替换当前动作，不积压队列；拖起优先于点击，动作完成后恢复基础状态。

安静模式暂停自动动作，显式互动结束后停止计时器；减少动效只改变静态表情。隐藏、收起到边缘、关闭、最小化、锁屏与睡眠停止时钟并取消当前动作，恢复时重新开始，不补播离开期间的动画。放松页切换内容时释放旧角色。

当前帧率是调度目标，不是硬件性能保证。增加动画会增加 GPU 合成和 CPU 工作量，应以资源回归观察和后续正式验收为依据。该实现没有增加网络调用、后台 API 成本或上传边界，模型替换也不能隐式加入网络下载或权限。

## 验证

核心测试覆盖动作时限、重复输入、拖动优先级、静止状态、有限数值与独立于采样频率的时间行为。`--smoke` 使用与现有角色形状不同、没有表情和骨骼的方块模型，检查动作复用、模型替换及旧实例释放；同时检查小屋换模型后的聊天拾取、表情网格拾取归属、几何复用及隐藏、安静、减少动效、收起、最小化和暂停后的计时器状态。

真实鼠标原生拖窗手感、硬件锁屏/休眠恢复、多屏 DPI 及长时间 GPU 稳定性仍需实际设备验收；程序化生命周期检查不替代这些验证。
