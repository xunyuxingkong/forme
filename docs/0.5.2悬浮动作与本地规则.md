# 0.5.2 悬浮动作与本地规则

## 使用方式

在“设置 → 伙伴角色、记忆与动作权限”开启宠物动作权限；要玩藏物、纸船、抛球和组合事件，开启玩法权限；灯光/物件/场景需要场景权限，家具草稿需要家具权限。

“自然动作规则 · 可编辑”中可开关本地规则优先、直接编辑JSON、保存、重新加载文件、恢复默认。实际文件为用户数据目录 `%LOCALAPPDATA%\Forme\interaction-rules.json`（自定义数据目录则在该目录），启动创建34条默认规则。不是修改项目的AGENTS.md；开发规则仍单独有效。可参考仓库中的[动作规则示例.json](动作规则示例.json)，示例只展示部分规则。

悬浮聊天可直接说“你能走两步吗？”“跑几步”“睡觉吧”“跳个舞”“随机走动”“随机奔跑”“别动”。短途移动按当前显示缩放和工作区寻找目标，走／跑完停下；减少动效模式直接到达。显式请求随机模式后，即使悬浮聊天开着也可运行；“别动”结束随机模式并回到原地待机。桌面召回先停下，不会猜测鼠标或用户位置。收起、隐藏、暂停时拒绝或中止动作。

说“陪我玩藏物”“玩纸船”“玩小球”“去书架旁”会打开必要的小屋页面。灯/读书/喂食等原有物件互动也可从悬浮聊天调用。场景里的游戏仍使用原有本地规则，不能在桌面空白处模拟不存在的家具。

## 匹配与执行边界

规则将表达映射为现有 `CompanionCommand`，支持最多3步明确连接的短句。匹配完整短句，允许有限的礼貌前缀与语气后缀；不扫描任意长文中的关键词。“不要走两步”“他说你能走两步吗”等不命中默认动作规则。“别动”是明确停止规则。规则可定义整句多步表达；若输入按连接词分段不命中，会检查整句规则。

命中规则时不需要API Key、不发网络请求，消息和真实结果标记为本地记录。未命中则使用已配置AI；无密钥时提示配置。复杂语义、引用与否定仍由外部AI理解，本地白名单与权限检查不允许越权，但不保证AI语义判断完全正确。可以在发送预览中看到将走本地规则或AI路径。

最多40条规则，每条1–10种表达、1–3个指令；UTF-8文件最多32KB。空/重复表达、未知字段、非法参数、系统命令等不能保存。加载错误会拒绝本地规则发送并提示修复，避免悄悄把本应本地处理的请求发送到服务商。新增规则不能绕过权限，也不能执行脚本、URL、文件操作或自定义代码。规则只在启动、保存、手动重新加载时读取，没有轮询。

两条路径共享执行器：逐项复检权限，等待短动作/移动结束，再执行后一步；整组最多30秒，可取消。纸船和藏物独立运行，不自动继续调用AI。

## 数据与项目约束

规则与命中的本地记录不发送给AI；以后普通聊天的上下文也排除本地记录。规则文件可能包含用户自定义表达，保存在用户数据目录；清除全部个人数据时删除并恢复默认。规则不包含密钥，也不自动扫描其它文件。规则暂不纳入小屋/聊天导出，可通过设置复制JSON迁移。

JSON导出格式升为6，保留本地消息状态；支持导入1–5旧备份。数据库结构不变；旧版不能读取新的6版导出，应先升级再导入。清空聊天删除本地聊天记录，清除全部数据重置自定义规则。

成本：命中本地规则不产生API费用；未命中沿用单次有界AI请求。延迟：本地匹配后直接反馈，不等待模型首字；未在本批给出硬件延迟承诺。资源：桌面短途移动复用已有动画回调，不新增常驻移动定时器，目标限当前屏幕工作区；规则限32KB且不轮询。维护：Core规则验证与匹配、统一执行器、已有模型适配层，普通用户可在界面定制，不修改源码。性能专项继续后置。
