# 0.5.3 宠物身体身份修正

聊天系统设定明确：屏幕上的宠物模型是伙伴在应用里的虚拟身体。允许自然承认有身体，不把缺少文件、系统或屏幕访问权限误解为不能操纵宠物。用户询问AI身份或现实生命时如实解释。旧聊天中“没有身体”的说法不延续。

动作请求必须调用现有授权指令，不能用括号描写代替实际动作。执行前使用准备语，成功与否由程序反馈；权限未开启或执行失败时说明原因，不声称已经完成。

默认转圈规则新增“转一圈”“转个圈”“转圈”，语气词处理允许“转一圈看看”。外部AI动作提示也明确映射到 `dance:spin`。启动时只升级完整、未修改的旧默认规则，不覆盖自定义配置；自定义规则可在原有转圈规则的 phrases 中添加这些表达。

约束：无新增API请求、后台轮询或数据采集。联网请求的固定身份提示略有增长，仍受原有上下文预算限制。常用转圈通过本地匹配，无API成本。动作仍使用原有动画适配层与权限检查。提示词不能保证所有外部模型遵从，确定性指令优先使用本地规则。

验证：52项Core测试通过，包含转圈自然表达、默认规则迁移/自定义保留、有无动作权限的身份提示与上下文预算。Release编译0警告、0错误；0.5.3安装包隔离解包自检通过。未调用真实付费API，外部模型的实际回复风格需使用用户配置的服务验证。本批没有运行性能专项或重复完整窗口回归。
