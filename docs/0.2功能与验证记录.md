# Forme 0.2 · 多伙伴、互动场景和可控记忆

更新日期：2026-10-10。此轮范围对应用户提出的模型、场景、性能、聊天记录、记忆、角色配置和 AI 控制设想。

## 可以使用的功能

1. 设置中的“伙伴模型与资源占用”提供芽芽伙伴、小猫、小狐狸、小企鹅。选择后点击“保存偏好”，小屋、桌面悬浮和揉揉活动共用这一形象。所有模型通过 `IPetModel` 接收同一套语义动作，动作与角色几何保持分离。
2. 小屋增加书架、鱼缸、零食碗、睡垫、落地灯与壁炉；户外增加池塘、木桥、野餐毯、凉亭、风铃和花草。点击物件让伙伴走过去并回应；灯和壁炉可以切换，浇水仍按每天一次去重。布置页提供同等文字入口。模型不会因未喂食而受惩罚。
3. 布置页可保存晴、雨、雪的静态天气布景以及灯和壁炉状态。静态天气层不启动持续粒子循环。点击空地仍使用寻路，池塘、家具、树木与边界限制移动；新点击或互动替换当前目标。
4. 聊天提供当前会话记录搜索、手动标题、会话摘要、消息复制，以及“存为记忆”编辑入口。会话按最近消息排序；标题仅在首条消息时自动生成。正常完成、停止和中断的回复都保存在本机。
5. 记忆由用户新增或确认，最多30条、每条400字，可编辑、启用、停用和删除；会话摘要最多800字。默认不分享记忆。开启后，只分享绑定当前服务商且启用的记录，优先摘要与最近编辑的内容，每次最多8段并受独立记忆及总上下文预算限制。切换服务商不会自动转移记忆，需要用户主动复制、检查并保存到当前服务。
6. “伙伴角色、记忆与动作权限”提供温柔朋友、专注搭子、故事伙伴和自定义角色。可配置1200字角色背景、400字语气偏好、上下文预算、128–1024 tokens 输出上限和回复随机性。聊天窗口中的发送预览显示实际将发出的 system、历史和本次消息内容，仅在本机生成。
7. 两个 AI 控制权限默认关闭，可分别允许宠物动作或场景变化。开启后可说“去户外，然后下雪”“跳一支摇摆舞”“关灯”“跑到 X=2、Z=3”。模型输出只作为意图，通过 `CompanionCommands` 白名单验证后在本机执行；每轮最多3个命令，只有完整且未截断、未停止的回复会执行。权限在执行前再次检查，结果追加在该回复下方。

## AI 控制边界

允许的动作：舞蹈、轻跳、揉揉、待机模式、合法场景坐标移动、室内外切换、静态天气、落地灯、壁炉，以及读书、零食、池塘、野餐、风铃、浇水和小球互动。

不提供文件、屏幕、剪贴板、系统、进程或网络访问；命令中不接受脚本、URL或可执行内容。AI 无法写入记忆、删除记录、购买家具、发放任意奖励或形成自主循环。每轮只消费当轮完成的命令；历史中的动作协议和本地结果不作为下一轮指令。不能到达、隐藏、最小化、锁屏或已关闭权限时会显示未执行结果。减少动效时使用静态反馈或立即到达合法点。场景切换会打开小屋，坐标移动需要可见的小屋。

真实服务可能不遵循文本动作协议，界面只执行实际收到且通过验证的指令，不把模型的口头承诺当作成功。未使用真实付费密钥联调；离线模拟覆盖文本协议、一次执行、清理保存与中断不执行。

## 成本、延迟、隐私和维护

- 不新增后台服务、模型下载、自动总结、嵌入检索或定时 AI 调用。添加模型、场景和记忆不调用 API；只有发送、重试与连接测试联网。单轮仍只有一个流式请求。
- 默认输出512 tokens、上下文4096的 UTF-8 保守字节预算。预算可选2048/4096/8192；它不是服务商的精确 token 计费数。角色设定和记忆会占用上下文，超预算则裁剪旧历史/记忆或拒绝过长输入，避免无限累积。
- 普通聊天、记忆和角色配置仍为本机明文 SQLite。密钥单独使用 Windows DPAPI。记忆分享需主动启用；导入聊天后关闭记忆分享，需重新开启。新增个人内容不进入诊断或自动上传。
- SQLite 迁移 v3→v4，升级前创建恢复副本；JSON 备份 v3 包含所选聊天类别的记忆和摘要，以及房间的模型和氛围配置，继续读取 v1/v2。AI 凭据、接口与角色配置不进入 JSON 备份。删除会话删除相应摘要，长期记忆独立管理；清空聊天同时清空记忆/摘要；删除也清理应用管理备份。
- 用户消息和回复占位记录在一个事务里保存；流式回复最多每3秒且内容增长至少64字符时写一次，结束时保存最终状态。预期的保存失败停止请求并保留内存中的最终回复，用户可复制、重试保存或明确放弃，避免静默丢失。
- 共用球面网格由768降到432个三角形，约减少43.75%；共享冻结的模型几何，表情缓存有界。单个小屋窗口最多缓存2个场景；隐藏及减少动效时停止动画。平衡模式待机10FPS、主动动作上限30FPS；省电模式待机5FPS、动作20FPS；睡眠与趴下休息2FPS、读书与观察5FPS、吃零食15FPS。这些是调度值，不能直接当作 CPU/GPU 降幅。
